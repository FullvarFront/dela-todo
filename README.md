# Дела

[Открыть список задач](https://fullvarfront.github.io/dela-todo/)

Введите название задачи и нажмите Enter. Галочка отмечает выполнение, корзина удаляет задачу. Фильтры показывают активные или готовые задачи. Список сохраняется в текущем браузере через `localStorage`.

## Запуск

Откройте `index.html` в браузере. Проект написан на HTML, CSS и JavaScript и работает без установки зависимостей.

## Использование AI

Для разработки использовался OpenAI Codex. С его помощью созданы интерфейс, иллюстрация блокнота и логика списка. Добавление, отметку выполнения, удаление и сохранение после обновления проверили в браузере.
